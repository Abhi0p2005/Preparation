1. Real Coupa OA Coding Questions (from recent drives)

Q1. Equal Subarrays (Array, Counting, Math) — Medium

Given array A of size N (non-negative ints). A subarray is any contiguous segment. Call a subarray equal if every entry has the same value. Return the total count of equal subarrays.

Solution: run-length encoding. Every maximal run of length L contributes L*(L+1)/2 subarrays. Sum over runs → O(N).

long count = 0; int run = 1;
for (int i = 1; i < n; i++) {
  if (a[i] == a[i-1]) run++;
  else { count += run*(run+1L)/2; run = 1; }
}
count += run*(run+1L)/2;

Q2. Sum of Subarray (Array, DP, Math) — Medium

Variant of "sum of all subarrays" / "sum of subarray minimums (907)" / "maximum subarray (53)". Read the problem carefully.

All-subarrays-sum formula: element A[i] (0-indexed) appears in (i+1)*(N-i) subarrays → contributes A[i]*(i+1)*(N-i). Use long.

Q3. Router Busy Light (String, Simulation, Counting) — Medium

Simulate network/router busy/idle intervals from string/range inputs; count overlapping busy ranges or total busy duration.

Practice: Merge Intervals (56), Meeting Rooms II (253), sweep-line counting, string parsing.

2. How to Attack Any OA Coding Problem

  1. Read the problem 3×. Underline input format, constraints, expected output.
  2. Name the pattern before coding: array → sort/two-pointer/window/prefix; tree/graph → BFS/DFS/topo/DSU; "max/min/count of ways" → DP; "smallest/largest value satisfying a condition" → binary search.
  3. Brute force first. Any correct answer then optimize. Partial credit beats a blank editor.
  4. Handle edge cases mentally: empty, single element, all same, negatives, overflow → long.
  5. Dry-run on the sample input on paper first.
  6. Timebox. Stuck >25–30 min → submit a stub/brute force, move on, return later.

    7. Common OA traps: integer overflow (use 64-bit), dividing by zero, off-by-one in window edges, not sorting before binary search, forgetting to reset state between test cases, O(n²) when n=10⁶.

3. THE PRE-SUBMIT CHECKLIST (30 seconds before submitting)

  • Loop bounds: n vs n−1, <= vs <, length vs length−1
  • Overflow: sum → long, 2×sum → long
  • Defensive copy: new ArrayList<>(list) before storing in Set
  • Fresh state per iteration: new copy inside loop
  • Empty input: n=0, arr=[] → handled?
  • Single element: n=1 → handled?
  • All same / all zeros / max values
  • Set vs List for dedup (Set O(1))
  • Return type matches (int vs long)
  • Guard clauses at top: if (arr == null || n == 0) return ...;

Output questions (C/C++ MCQs)

  • Trace the code line by line with concrete values — never eyeball.
  • Two's complement: use range bounds (−128..127 for int8).
  • Watch: unsigned conversion, sizeof vs strlen, struct padding, pre/post increment, macro expansion.
