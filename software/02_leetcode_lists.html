10. Dynamic Programming (Core)

Problem TypePatternDiffSimplified Approach
Climbing Stairs1D DPEdp[i] = dp[i-1] + dp[i-2]. Base: dp[0]=1, dp[1]=1.
House Robber1D DPMdp[i] = max(nums[i] + dp[i-2], dp[i-1]). Can optimize to two variables.
House Robber II (Circular)1D DPMTwo cases: rob [0..n-2] or [1..n-1]. Return max of both.
Coin ChangeUnbounded KnapsackMdp[amount] = min coins to make amount. dp[i] = min(dp[i], dp[i-coin] + 1).
Longest Increasing Subsequence1D DPMdp[i] = LIS ending at i. Check all j < i where nums[j] < nums[i]. Or binary search O(n log n).
Maximum Product Subarray1D DPMTrack max and min (negatives flip sign). Update both at each step.
Word Break1D DPMdp[i] = can break s[0..i-1]. Check if dp[j] AND s[j..i] in dict.
Longest Palindromic Substring2D DP / ExpandMExpand around center (odd/even length). Or 2D dp[i][j] = is s[i..j] palindrome.
Palindromic SubstringsExpand Around CenterMFor each center (single char / two chars), expand while palindrome. Count.
Maximal Square2D DPMdp[i][j] = side length of square ending at (i,j). dp[i][j] = min(top, left, diag) + 1.
Unique Paths2D DPMdp[i][j] = ways to reach (i,j). dp[i][j] = dp[i-1][j] + dp[i][j-1].
Minimum Path Sum2D DPMdp[i][j] = min cost to reach (i,j). dp[i][j] = grid[i][j] + min(top, left).
Longest Common Subsequence2D DPMIf s1[i] == s2[j]: dp[i][j] = dp[i-1][j-1] + 1. Else: max(dp[i-1][j], dp[i][j-1]).
Edit Distance2D DPHIf chars match: dp[i][j] = dp[i-1][j-1]. Else: 1 + min(insert, delete, replace).
Regular Expression Matching2D DPHHandle '*' matching 0 or more. dp[i][j] = does s[0..i-1] match p[0..j-1].
Distinct Subsequences2D DPHCount ways to form t from s. If match: dp[i][j] = dp[i-1][j-1] + dp[i-1][j].
Partition Equal Subset Sum0/1 KnapsackMCheck if subset with sum = total/2 exists. dp[sum] = can we make this sum.
Target Sum0/1 KnapsackMConvert to subset sum: find subset with sum = (total + target) / 2.
Last Stone Weight II0/1 KnapsackMMinimize difference between two groups. Find subset closest to total/2.
Ones and Zeroes2D KnapsackM2D dp[m][n] = max strings with m zeros and n ones. Iterate strings backwards.
Burst BalloonsInterval DPHdp[i][j] = max coins bursting balloons i..j. Try each as last balloon to burst.
Best Time to Buy/Sell Stock IVState Machine DPHTrack max profit with k transactions. dp[i][k][0/1] = cash after i days, k trans, holding/not.
Best Time to Buy/Sell Stock IIIState Machine DPHSpecial case of k=2. Track 4 states: buy1, sell1, buy2, sell2.
Max Sum of 3 Non-Overlapping SubarraysDP + PrecomputeHPrecompute sums. Track best left, best right indices. Check middle positions.
Word Break IIDP + BacktrackingHMemoized DFS. At each position, try all valid words. Build sentences recursively.
Russian Doll EnvelopesLIS VariantHSort by width asc, height desc. Find LIS on heights using binary search.
Substring with Largest VarianceKadane VariantHFor each pair of chars (a, b), run Kadane treating a as +1, b as -1.
Maximum Profit in Job SchedulingDP + Binary SearchHSort by end time. dp[i] = max profit up to job i. Binary search for last non-overlapping.

13. One-Day Intensive Drill Plan

Structured practice plan for comprehensive DSA revision in a single day.

  • Block A (90 min) - Pattern Mastery: Two Sum, Longest Substring Without Repeating, Valid Parentheses, Min Stack, Daily Temperatures, Level Order Traversal, Course Schedule, Coin Change, Merge Intervals, Single Number.
  • Block B (60 min) - Hard Problems: Sliding Window Maximum, Minimum Window Substring, Find Median from Data Stream, Burst Balloons.
  • Block C (45 min) - Pattern Combination: Create hybrid problems (e.g., "sliding window max on a stream", "median in rolling window").
  • Block D (30 min) - Speed Round: Re-solve Reverse Linked List, Merge Two Sorted Lists, Detect Cycle, Maximum Depth mentally without coding.

OA Strategy: If stuck on hard problem: (1) Read problem 3 times (2) Map to pattern (3) Write brute force first for partial credit (4) Optimize after samples pass (5) If blocked >25-30 min, submit working solution and move on.
