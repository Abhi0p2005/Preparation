DATA SCIENCE & ML — COMPLETE GUIDE

ML pipeline, algorithms, evaluation, statistics & probability, Bayes, hypothesis testing, SQL for DS, pandas. For DS/data-engineer roles (PhonePe, TresVista, etc.).

1. AI vs ML vs DL vs LLM

  • AI — any machine doing "smart" things (umbrella term)
  • ML — machines that learn patterns from data instead of explicit rules
  • DL — ML using big multi-layer neural networks
  • LLM — deep-learning model trained on enormous text that predicts the next word

Analogy: AI = vehicle, ML = car, DL = electric car, LLM = a specific Tesla model.

3. The ML Pipeline (memorize the order)

  1. Business problem → ML problem
  2. Data collection / sourcing
  3. Clean data (missing values, outliers, dtypes, duplicates, leakage)
  4. Feature engineering (create columns, scale, encode)
  5. Split: train / validation / test
  6. Model + hyperparameter tuning (on validation, NEVER test)
  7. Evaluate, deploy, monitor (watch for drift)

Leakage: if future/test information reaches training, the model looks amazing in testing but fails in production. Split BEFORE any feature fitting.

5. Evaluation & Diagnostics (most-asked MCQs)

Confusion matrix & metrics

MetricMeaningFormula
Accuracyall correct / all(TP+TN)/(all)
Precisionof predicted positives, how many were truly positiveTP/(TP+FP)
Recall (Sensitivity)of actual positives, how many we caughtTP/(TP+FN)
Specificityof actual negatives, how many stayed negativeTN/(TN+FP)
F1balanced P+R2PR/(P+R)

Accuracy trap: with 0.01% fraud, a model that never calls fraud is 99.99% "accurate" — and useless. Judge rare classes with precision, recall, F1, PR-AUC.

  • ROC-AUC: P(random positive ranked above random negative); 0.5 = random, 1 = perfect. On imbalanced data use PR-AUC instead.
  • Overfitting (high variance) — memorizes training noise. Fixes: more data, regularization, fewer features, simpler model, CV, early stopping, dropout.
  • Underfitting (high bias) — too simple. Fixes: more features, more complex model, lower regularization.
  • k-fold CV: split into k parts, train k−1, validate 1. Stratified for imbalanced classes.

Regularization

  • L1 (Lasso): |weight| penalty → shrinks some weights EXACTLY to 0 → feature selection.
  • L2 (Ridge): weight² penalty → shrinks all toward 0 (never zero) → handles multicollinearity.
  • ElasticNet: both.

6. Deep Learning & LLMs (intuition)

  • Neuron: inputs × weights + bias → activation → output.
  • Activations: ReLU (default hidden), sigmoid (0-1 binary), tanh (−1..1), softmax (multi-class sum 1).
  • Training: forward pass → loss → backpropagation (chain rule) → update weight −= lr × gradient. Small lr = slow but stable; too large = jumps over minimum.
  • CNN: convolution (filters/kernels) + pooling (downsample) + dense layers. Transfer learning reuses ImageNet weights.
  • RNN/LSTM: sequential data; RNNs suffer vanishing gradients; LSTM/GRU add gates.
  • Transformers: self-attention — every token looks at every other token, weights importance; trains in parallel. LLMs predict the next word. Embeddings = dense vectors capturing meaning.

7. Statistics & Probability (biggest MCQ source)

Descriptive stats

  • Mean (sensitive to outliers), Median (robust), Mode.
  • Variance = avg squared distance from mean; sample variance divides by n−1 (Bessel's correction). SD = √variance.
  • CV = σ/μ (unit-free). Skew: right-skewed → mean > median > mode.
  • IQR = Q3−Q1; outliers beyond Q1−1.5·IQR, Q3+1.5·IQR. z-score = (x−μ)/σ.
  • Correlation r ∈ [−1,1], unit-free. r=0 ⇒ no LINEAR correlation, NOT independence. Correlation ≠ causation.

Probability rules

  • P(A∪B) = P(A)+P(B)−P(A∩B). Independent: P(A∩B)=P(A)P(B). Mutually exclusive: P(A∩B)=0.
  • Conditional: P(A|B) = P(A∩B)/P(B). Bayes: P(A|B) = P(B|A)P(A)/P(B) — most-asked concept.
  • E[X+Y] = E[X]+E[Y] always. Var(aX+b) = a²Var(X). Var(X+Y) = Var(X)+Var(Y)+2Cov(X,Y).
Bayes classic: disease prevalence 1%, sensitivity & specificity 99%. P(disease | positive)?

= (0.99·0.01)/(0.99·0.01 + 0.01·0.99) = 0.50. At low prevalence, half your "positives" are false positives.

8. Hypothesis Testing (JD-listed skill)

  • H0 (skeptical default) vs H1 → pick test → compute statistic → compare p-value vs α.
  • p-value: P(data as extreme as observed | H0 true). Small p = evidence against H0. NOT "P(H0 is true)".
  • Type I (α): reject a true H0 (false alarm). Type II (β): fail to reject a false H0 (miss). Power = 1−β.
  • z-test if σ known or n large; t-test (df=n−1) when σ estimated. One-sample t = (x̄−μ)/(s/√n). Paired t on differences.
  • Chi-square Σ(O−E)²/E — categorical independence. ANOVA (F) — compare 3+ group means.
  • Heavy-tailed data (e.g. UPI amounts): t-test unreliable → use Mann-Whitney U (non-parametric) or bootstrap CI, or log-transform.
  • Multiple testing: 10 metrics → Bonferroni (α/10) or Benjamini-Hochberg FDR.

Confidence intervals

x̄ ± z·σ/√n or x̄ ± t·s/√n. Correct reading: "~95% of repeated intervals would contain the true mean" — NOT "95% chance the mean is in this interval".

Linear algebra quick 20%

Dot product = Σxi·yi. Cosine similarity = (A·B)/(|A||B|). Eigenvalue A·v=λ·v. PCA = eigenvectors of covariance; eigenvalue = variance explained. L2 = √Σxi² (Euclidean), L1 = Σ|xi| (Manhattan).

10. Business Metrics & A/B Testing

  • DAU/MAU, stickiness = DAU/MAU, retention, conversion rate, churn = 1−retention, ARPU/ARPPU, take rate, LTV vs CAC (healthy if LTV > CAC).
  • AARRR: Acquisition → Activation → Retention → Revenue → Referral.
  • A/B test steps: hypothesis → random split → sample size (from effect size, α, power BEFORE running) → run → test → interpret (p<0.05 significant; but check effect size).
  • Watch outs: novelty effect, Simpson's paradox, multiple-testing inflation, peeking.

variance (RF); bias (XGBoost).

Which regularization sets coefficients exactly to 0?

Lasso (L1) → feature selection.

Check precision/recall and PR-AUC — accuracy is misleading with rare classes.
