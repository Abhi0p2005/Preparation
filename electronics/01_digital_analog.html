DIGITAL + ANALOG + SIGNALS & SYSTEMS

Number systems, Boolean/K-maps, combinational & sequential circuits, memories, op-amps, diodes, transistors, signals, communication.

1. Number Systems

  • Binary, octal, hex, BCD. Each hex digit = 4 bits: 0=0000 ... F=1111. 0xA5 = 1010 0101.
  • Two's complement (negative numbers): invert all bits + 1. Example −5 (8-bit): 00000101 → invert 11111010 → +1 → 11111011. Why: 5 + (−5) = 0 with normal addition hardware.
  • 8-bit ranges: unsigned 0–255, signed −128 to 127.
  • ASCII: 'A'=65, 'a'=97, '0'=48.
  • C octal trap: int x = 052; → x = 42 (leading zero = octal), not 52.

K-map rules

  • Groups of 1, 2, 4, 8, 16 (powers of 2), rectangular, can wrap around edges.
  • Each 1 must be covered at least once; larger groups = simpler expression.
  • Don't cares (X) can be 0 or 1 to maximize group size.

3. Combinational Circuits

  • Half adder: S = A⊕B, C = AB.
  • Full adder: S = A⊕B⊕Cin, Cout = AB + Cin(A⊕B).
  • MUX (2ⁿ:1 picks with n select bits), DEMUX, decoder, encoder, priority encoder, comparator.
  • NAND and NOR are universal gates — all others can be built from them.

4. Sequential Circuits

  • Flip-flops: SR (invalid at 11), JK (no invalid state), D (Q=D edge-triggered), T (toggles).
  • Race condition in SR latch when S=R=1.
  • Registers, shift registers (SISO/SIPO/PISO/PIPO), ring / Johnson counters.
  • Synchronous vs asynchronous counters; MOD-n counters.
  • Frequency division: T flip-flop ÷2; cascade n FFs = ÷2ⁿ.

5. Memories — SRAM / DRAM / Cache / Flash / FIFO / ECC

  • SRAM cells: 6T (standard) · 8T (separate read port → better read stability, higher SNM) · 10T (low voltage). SNM = static noise margin, max DC noise without flipping; read SNM < hold SNM.
  • DRAM operation: RAS# asserts row → row copied to sense amps → CAS# selects column. Refresh every row every 64 ms. DDR = double data rate.

Cache memory architecture

CPU → L1 (per-core, split I$+D$, 32-64KB, 2-4 cycles)
     → L2 (256KB-2MB, 10-20 cycles)
     → L3 (shared, 2-32MB, 30-50 cycles)
     → DRAM (100+ cycles)
  • Cache params: Total = Sets × Associativity × Block. Sets = size/(assoc×block). Address = [Tag | Index | Offset]. Index bits = log2(sets), offset bits = log2(block).
  • Replacement: LRU, FIFO, Random, Pseudo-LRU. Write: write-through (no dirty bit, high traffic) vs write-back (dirty bit, complex coherency).

FIFO depth calculation

Given write rate fw, read rate fr, burst B → depth = B × (1 − fr/fw). Example: 100 MHz write, 80 MHz read, burst 100 → 100 × 0.2 = 20.

ECC

  • Parity: single bit, detects odd number of errors (simple XOR).
  • Hamming SECDED: correct single, detect double. For d data bits: 2^p ≥ d + p + 1. 8 data → 4 parity → 12-bit codeword; 16 data → 5 parity.

6. Analog Electronics

Diodes & rectifiers

  • Half-wave: ripple factor 1.21, PIV=Vm. Full-wave center-tap: 0.48, PIV=2Vm. Bridge: 0.48, PIV=Vm.
  • Zener operates in reverse breakdown → voltage regulation.
  • Ideal diode: ON when forward biased, OFF when reverse.

Transistors

  • BJT = current-controlled (Ic ≈ β·Ib). Configs: CE (voltage gain ≈ −gm·Rc), CB, CC (emitter follower, buffer).
  • Biasing: fixed, voltage-divider (stabilizes Q-point).
  • MOSFET = voltage-controlled. Regions: cutoff, triode/linear, saturation. Vgs(th) threshold.

Op-amp (memorize these)

  • Ideal op-amp rules: V+ = V− (virtual short), input current = 0, infinite gain, infinite input impedance, zero output impedance.
  • Inverting gain = −Rf/R1 · Non-inverting gain = 1 + Rf/R1.
  • Summing amplifier, integrator (cap feedback), differentiator, comparator (saturates, no feedback).

Feedback & filters

  • Negative feedback: lowers gain, increases bandwidth & stability. Positive feedback → oscillators.
  • RC low-pass cutoff fc = 1/(2πRC). Series/parallel resonance, Q-factor.

7. Signals & Systems

  • Fourier series (periodic), Fourier transform (aperiodic), Laplace transform (ROC, poles/zeros), Z-transform (discrete).
  • Convolution, correlation, Parseval. Even/odd, periodic, power vs energy signals.
  • LTI systems: linearity, time-invariance, causality (no future input), stability (poles in LHP / inside unit circle).
  • Sampling (Nyquist): fs ≥ 2·fmax else aliasing. Nyquist rate = 2× max frequency.
  • Classic: y(n) = x(n−1) + 2x(n+1) → not causal (uses future input).
  • System y depends only on current/past inputs → causal; Ω/unit circle for stability.

8. Communication

  • AM: bandwidth = 2fm, modulation index m, sidebands fc±fm.
  • FM: bandwidth ≈ 2(Δf + fm) (Carson's rule).
  • Digital modulation: ASK/FSK/PSK/QPSK.
  • Shannon: C = B·log₂(1+SNR).
  • Multiplexing: FDM (analog), TDM (digital), CDMA/OFDM.

9. Memory / Digital MCQ Practice

A 6T SRAM cell uses how many transistors?

6 — 2 cross-coupled inverters (4) + 2 access transistors.

Why does DRAM need refresh?

Capacitor charge leaks over time (~64ms).

Cache 32KB, 64B blocks, 8-way set-assoc — index bits?

Sets = 32768/(8×64) = 64 → log2(64) = 6 bits.

Hamming SECDED with 16 data bits — parity bits?

2^5=32 ≥ 16+5+1=22 → 5.

FIFO written 200 MHz, read 150 MHz, burst 60?

60 × (1 − 150/200) = 60 × 0.25 = 15.

Which SRAM cell has best read stability?

8T — separate read port, no read-disturb.

Row address strobe in DRAM?

RAS# — row access strobe.
