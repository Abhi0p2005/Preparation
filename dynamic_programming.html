Dynamic Programming

Master optimal substructure and overlapping subproblems

1. DP Fundamentals

What is Dynamic Programming?

  • Definition: Optimization technique for problems with overlapping subproblems and optimal substructure.
  • Optimal Substructure: Optimal solution contains optimal solutions to subproblems.
  • Overlapping Subproblems: Same subproblems solved multiple times.
  • Key Idea: Store results of subproblems (memoization) to avoid recomputation.

Two Approaches

// 1. Memoization (Top-Down): Recursion + Cache
int fib(int n, int[] memo) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    memo[n] = fib(n-1, memo) + fib(n-2, memo);
    return memo[n];
}

// 2. Tabulation (Bottom-Up): Iterative + Array
int fib(int n) {
    if (n <= 1) return n;
    int[] dp = new int[n+1];
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
💡 When to use DP: If you can solve problem recursively but see repeated subproblems (drawing recursion tree shows overlaps), use DP. Ask: "Can I break this into smaller similar problems?"

DP Problem-Solving Steps

  1. Define State: What parameters change? dp[i] represents what?
  2. Base Cases: What are the simplest cases? Initialize them.
  3. Recurrence Relation: How to compute dp[i] from previous states?
  4. Iteration Order: Which order ensures dependencies are computed first?
  5. Space Optimization: Can we reduce from 2D to 1D, or to O(1)?

2. 1D Dynamic Programming

Linear DP Problems

70 Climbing Stairs Easy dp[i] = ways to reach step i = dp[i-1] + dp[i-2]. Base: dp[0]=1, dp[1]=1. Fibonacci pattern. Space optimize: two variables instead of array.
198 House Robber Medium dp[i] = max money robbing up to house i = max(nums[i] + dp[i-2], dp[i-1]). Can't rob adjacent. Base: dp[0]=nums[0], dp[1]=max(nums[0],nums[1]). Optimize to O(1) space.
213 House Robber II (Circular) Medium Houses in circle: can't rob both first and last. Run House Robber I twice: (1) houses [0..n-2], (2) houses [1..n-1]. Return max of both.
91 Decode Ways Medium dp[i] = ways to decode s[0..i-1]. If s[i-1] valid (1-9): dp[i] += dp[i-1]. If s[i-2:i] valid (10-26): dp[i] += dp[i-2]. Handle '0' carefully.
322 Coin Change Medium dp[amount] = min coins to make amount. For each coin: dp[i] = min(dp[i], dp[i-coin] + 1). Base: dp[0]=0. Return dp[amount] or -1 if impossible.
152 Maximum Product Subarray Medium Track max_prod and min_prod (negatives flip). For each num: new_max = max(num, num*max_prod, num*min_prod). Update min similarly. Track global max.
300 Longest Increasing Subsequence Medium dp[i] = LIS ending at i. For each j < i where nums[j] < nums[i]: dp[i] = max(dp[i], dp[j]+1). O(n²). Optimize: binary search on tails array O(n log n).

120 Triangle Medium Bottom-up: dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1]). Start from bottom row. Return dp[0][0]. Space optimize: use 1D array.

4. Knapsack Patterns

0/1 Knapsack (Each item once)

// dp[i][w] = max value using first i items with weight limit w
for (int i = 1; i <= n; i++) {
    for (int w = 0; w <= capacity; w++) {
        if (weight[i-1] <= w) {
            dp[i][w] = max(
                dp[i-1][w],                          // don't take
                value[i-1] + dp[i-1][w-weight[i-1]] // take
            );
        } else {
            dp[i][w] = dp[i-1][w]; // can't take
        }
    }
}

// Space optimize: 1D array, iterate backwards
for (int i = 0; i < n; i++) {
    for (int w = capacity; w >= weight[i]; w--) {
        dp[w] = max(dp[w], value[i] + dp[w-weight[i]]);
    }
}

Unbounded Knapsack (Unlimited items)

// Can take item multiple times
for (int i = 0; i < n; i++) {
    for (int w = weight[i]; w <= capacity; w++) { // iterate forwards
        dp[w] = max(dp[w], value[i] + dp[w-weight[i]]);
    }
}

Knapsack Problems

LC#ProblemDifficultySolution Approach
416 Partition Equal Subset Sum Medium Check if subset with sum = total/2 exists. 0/1 knapsack: dp[sum] = can we make this sum. For each num, update dp[sum] if dp[sum-num] is true. Iterate backwards.
494 Target Sum Medium Convert to subset sum: find subset S where sum(S) - sum(rest) = target. Rearrange: sum(S) = (total + target) / 2. Count subsets with this sum using 0/1 knapsack DP.
1049 Last Stone Weight II Medium Minimize difference between two groups. Find subset closest to total/2. Use knapsack DP to find max sum <= total/2. Answer = total - 2*max_sum.
474 Ones and Zeroes Medium 2D knapsack: dp[m][n] = max strings with m zeros, n ones. For each string, count zeros/ones. Update dp backwards: dp[i][j] = max(dp[i][j], 1 + dp[i-zeros][j-ones]).
518 Coin Change II Medium Unbounded knapsack: count ways to make amount. dp[i] = ways to make i. For each coin, for amount from coin to target: dp[amount] += dp[amount - coin]. Iterate forwards.

5. String DP

Longest Common Subsequence (LCS)

// dp[i][j] = LCS length of s1[0..i-1] and s2[0..j-1]
for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        if (s1[i-1] == s2[j-1]) {
            dp[i][j] = dp[i-1][j-1] + 1;
        } else {
            dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
}

Edit Distance

// dp[i][j] = min operations to convert s1[0..i-1] to s2[0..j-1]
for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        if (s1[i-1] == s2[j-1]) {
            dp[i][j] = dp[i-1][j-1]; // no operation
        } else {
            dp[i][j] = 1 + min({
                dp[i-1][j],    // delete from s1
                dp[i][j-1],    // insert into s1
                dp[i-1][j-1]   // replace
            });
        }
    }
}

String DP Problems

LC#ProblemDifficultySolution Approach
1143 Longest Common Subsequence Medium 2D DP: if chars match, dp[i][j] = dp[i-1][j-1] + 1. Else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]). Space optimize: use 1D array.
72 Edit Distance Hard 2D DP: if chars match, no operation. Else: 1 + min(delete, insert, replace). Base: dp[i][0]=i (delete all), dp[0][j]=j (insert all).
5 Longest Palindromic Substring Medium Expand around center: Try each position as center (odd/even length). DP: dp[i][j] = is s[i..j] palindrome. dp[i][j] = (s[i]==s[j]) && dp[i+1][j-1].
647 Palindromic Substrings Medium Expand around center: for each center, expand while chars match. Count palindromes. Or 2D DP: count dp[i][j] where is_palindrome is true.
139 Word Break Medium dp[i] = can we segment s[0..i-1]. For each i, check all j < i: if dp[j] && s[j..i-1] in dict, dp[i]=true. Base: dp[0]=true (empty string).
140 Word Break II Hard Memoized DFS. At each position, try all valid words from dict. If word matches, recurse on remaining. Build sentences. Use memo to avoid recomputation.
115 Distinct Subsequences Hard dp[i][j] = count ways to form t[0..j-1] from s[0..i-1]. If s[i-1]==t[j-1]: dp[i][j] = dp[i-1][j-1] (use char) + dp[i-1][j] (skip char). Else: dp[i][j] = dp[i-1][j].

6. Advanced DP Patterns

Interval DP

LC#ProblemDifficultySolution Approach
312 Burst Balloons Hard dp[i][j] = max coins bursting balloons (i..j). For each k in [i..j], assume k is LAST to burst: dp[i][j] = max(nums[i-1]*nums[k]*nums[j+1] + dp[i][k-1] + dp[k+1][j]). Add 1s at boundaries.
1130 Min Cost Tree From Leaf Values Medium Interval DP: dp[i][j] = min cost for subarray [i..j]. Try each split point k: dp[i][j] = min(dp[i][k] + dp[k+1][j] + max(arr[i..k]) * max(arr[k+1..j])). Or greedy stack.
546 Remove Boxes Hard 3D DP: dp[i][j][k] = max points removing boxes[i..j] with k same-color boxes before i. Complex state transitions considering merging same colors.

State Machine DP

LC#ProblemDifficultySolution Approach
309 Stock with Cooldown Medium 3 states: hold, sold, rest. hold[i] = max(hold[i-1], rest[i-1]-price). sold[i] = hold[i-1]+price. rest[i] = max(rest[i-1], sold[i-1]). Track transitions.
188 Stock with K Transactions Hard dp[i][k][0/1] = max profit after i days, k transactions, holding(1) or not(0). Transitions: buy (k-1, 0→1), sell (k, 1→0), rest. Optimize: if k >= n/2, unlimited.

DP with Binary Search

LC#ProblemDifficultySolution Approach
354 Russian Doll Envelopes Hard Sort by width asc, height desc. Find LIS on heights using binary search. Descending height ensures same width envelopes don't nest. O(n log n).
1235 Maximum Profit Job Scheduling Hard Sort by end time. dp[i] = max profit up to job i. For each job: binary search for last non-overlapping job. dp[i] = max(dp[i-1], profit[i] + dp[last]).

7. Practice Strategy

Learning Path (6 Weeks)

  1. Week 1 - 1D DP Basics: Climbing Stairs, House Robber, Decode Ways, Coin Change
  2. Week 2 - 1D Advanced: LIS, Max Product Subarray, Jump Game variants
  3. Week 3 - 2D Grid: Unique Paths, Min Path Sum, Maximal Square, Triangle
  4. Week 4 - Knapsack: Partition Equal Subset Sum, Target Sum, Coin Change II
  5. Week 5 - Strings: LCS, Edit Distance, Palindrome problems, Word Break
  6. Week 6 - Advanced: Burst Balloons, Stock problems, Interval DP
📝 Interview Tips:
  • Always start with recursive solution, identify overlapping subproblems
  • Define state clearly: "dp[i] represents..."
  • Write down base cases explicitly
  • Draw small example (n=4) and fill DP table manually
  • State time/space complexity: often O(n²) time, O(n) or O(n²) space
  • Mention space optimization if applicable (2D→1D, rolling array)
  • For 2D DP, clarify iteration order (usually row-by-row or diagonal)

Common Mistakes

  • ❌ Not initializing base cases correctly
  • ❌ Off-by-one errors in array indices (especially dp[i-1])
  • ❌ Wrong iteration order causing access to uncomputed states
  • ❌ Forgetting to handle edge cases (empty input, n=1)
  • ❌ In knapsack, iterating forwards when should go backwards (or vice versa)
  • ❌ Not considering space optimization after solving
  • ❌ In string DP, confusing i and i-1 indexing between dp array and string
