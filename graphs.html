Graphs

Master graph traversal, shortest paths, topological sort, and union-find

1. Graph Fundamentals

Core Concepts

  • Graph: Set of vertices (nodes) connected by edges.
  • Directed vs Undirected: Edges have direction or not.
  • Weighted vs Unweighted: Edges have weights or all equal.
  • Connected: Path exists between every pair of vertices.
  • Cycle: Path that starts and ends at same vertex.
  • DAG: Directed Acyclic Graph - directed with no cycles.

Graph Representations

// Adjacency List (most common for sparse graphs)
Map> graph = new HashMap<>();
// For node u -> v: graph.get(u).add(v);

// Adjacency Matrix (for dense graphs)
int[][] graph = new int[n][n];
// For edge u -> v: graph[u][v] = 1 (or weight);

// Edge List (for some algorithms like Kruskal's)
List edges = new ArrayList<>();
// edges.add(new int[]{u, v, weight});
💡 Space Complexity: Adjacency List: O(V + E). Adjacency Matrix: O(V²). Prefer adjacency list unless graph is dense (E ≈ V²).

2. BFS & DFS Traversal

Breadth-First Search (BFS)

Explores level by level. Uses queue. Finds shortest path in unweighted graph.

void bfs(int start) {
    Queue q = new LinkedList<>();
    Set visited = new HashSet<>();
    q.offer(start);
    visited.add(start);
    
    while (!q.isEmpty()) {
        int node = q.poll();
        // Process node
        
        for (int neighbor : graph.get(node)) {
            if (!visited.contains(neighbor)) {
                visited.add(neighbor);
                q.offer(neighbor);
            }
        }
    }
}

Depth-First Search (DFS)

Explores as deep as possible. Uses recursion or stack. Detects cycles, finds components.

void dfs(int node, Set visited) {
    visited.add(node);
    // Process node
    
    for (int neighbor : graph.get(node)) {
        if (!visited.contains(neighbor)) {
            dfs(neighbor, visited);
        }
    }
}
⚠️ When to use BFS vs DFS:
  • BFS: Shortest path (unweighted), level-order, minimum steps
  • DFS: Cycle detection, topological sort, component finding, backtracking

3. Shortest Path Algorithms

BFS for Unweighted Graphs

BFS naturally finds shortest path in unweighted graphs. Track distance or parent to reconstruct path.

Dijkstra's Algorithm (Non-negative Weights)

// Priority Queue (min-heap) with (distance, node)
int[] dijkstra(int start, int n) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    
    PriorityQueue pq = new PriorityQueue<>((a,b) -> a[0] - b[0]);
    pq.offer(new int[]{0, start}); // {distance, node}
    
    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int d = curr[0], u = curr[1];
        
        if (d > dist[u]) continue; // outdated entry
        
        for (int[] edge : graph.get(u)) {
            int v = edge[0], weight = edge[1];
            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    return dist;
}

Bellman-Ford (Handles Negative Weights)

// Relax all edges V-1 times
int[] bellmanFord(int start, int V, List edges) {
    int[] dist = new int[V];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    
    for (int i = 0; i < V - 1; i++) {
        for (int[] edge : edges) {
            int u = edge[0], v = edge[1], w = edge[2];
            if (dist[u] != INF && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
            }
        }
    }
    
    // Check negative cycle
    for (int[] edge : edges) {
        int u = edge[0], v = edge[1], w = edge[2];
        if (dist[u] + w < dist[v]) return null; // negative cycle
    }
    return dist;
}

4. Topological Sort & Cycle Detection

Topological Sort (DAG only)

Linear ordering where for edge u→v, u comes before v.

Kahn's Algorithm (BFS-based)

List topologicalSort(int n, List edges) {
    int[] indegree = new int[n];
    Map> graph = new HashMap<>();
    
    // Build graph and compute indegree
    for (int[] edge : edges) {
        graph.putIfAbsent(edge[0], new ArrayList<>());
        graph.get(edge[0]).add(edge[1]);
        indegree[edge[1]]++;
    }
    
    // Add nodes with indegree 0
    Queue q = new LinkedList<>();
    for (int i = 0; i < n; i++) {
        if (indegree[i] == 0) q.offer(i);
    }
    
    List result = new ArrayList<>();
    while (!q.isEmpty()) {
        int node = q.poll();
        result.add(node);
        
        for (int neighbor : graph.getOrDefault(node, new ArrayList<>())) {
            indegree[neighbor]--;
            if (indegree[neighbor] == 0) q.offer(neighbor);
        }
    }
    
    return result.size() == n ? result : new ArrayList<>(); // cycle if size < n
}

DFS-based (with cycle detection)

// 3 states: 0=unvisited, 1=visiting, 2=visited
boolean dfs(int node, int[] state, List result) {
    if (state[node] == 1) return false; // cycle (back edge)
    if (state[node] == 2) return true;  // already processed
    
    state[node] = 1; // mark visiting
    for (int neighbor : graph.get(node)) {
        if (!dfs(neighbor, state, result)) return false;
    }
    state[node] = 2; // mark visited
    result.add(0, node); // add to front (reverse postorder)
    return true;
}

5. Union-Find (Disjoint Set Union)

Union-Find Data Structure

Efficiently tracks connected components. Supports union and find operations.

class UnionFind {
    int[] parent, rank;
    int components;
    
    UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        components = n;
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    
    // Find with path compression
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // path compression
        }
        return parent[x];
    }
    
    // Union by rank
    boolean union(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX == rootY) return false; // already connected
        
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        components--;
        return true;
    }
    
    boolean connected(int x, int y) {
        return find(x) == find(y);
    }
}
💡 Time Complexity: With path compression and union by rank, operations are nearly O(1) - precisely O(α(n)) where α is inverse Ackermann function.

6. Minimum Spanning Tree

Kruskal's Algorithm (Union-Find)

int kruskal(int n, List edges) {
    // Sort edges by weight
    Collections.sort(edges, (a,b) -> a[2] - b[2]);
    
    UnionFind uf = new UnionFind(n);
    int mstCost = 0, edgesUsed = 0;
    
    for (int[] edge : edges) {
        int u = edge[0], v = edge[1], weight = edge[2];
        if (uf.union(u, v)) {
            mstCost += weight;
            edgesUsed++;
            if (edgesUsed == n - 1) break; // MST complete
        }
    }
    
    return edgesUsed == n - 1 ? mstCost : -1; // -1 if not connected
}

8. Practice Strategy

Learning Path (4 Weeks)

  1. Week 1 - Traversal: Number of Islands, Clone Graph, Max Area of Island, Pacific Atlantic
  2. Week 2 - Shortest Path: Network Delay Time, Shortest Path in Binary Matrix, Word Ladder, Dijkstra practice
  3. Week 3 - Topological Sort: Course Schedule I & II, Alien Dictionary
  4. Week 4 - Union-Find & MST: Number of Provinces, Redundant Connection, Accounts Merge, Min Cost Connect Points
📝 Interview Tips:
  • Always clarify: directed or undirected? weighted? cycles allowed?
  • Ask about graph size: affects choice of representation
  • Discuss time/space: BFS O(V+E) time, O(V) space; Dijkstra O((V+E)logV)
  • For matrix problems, mention treating as graph with 4/8 directions
  • Topological sort only works on DAGs - mention cycle detection
  • Union-Find optimal for dynamic connectivity, component queries
