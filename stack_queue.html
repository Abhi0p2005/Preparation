Stack & Queue

Master LIFO and FIFO data structures with monotonic stack patterns

1. Stack Fundamentals

Core Concepts

  • Stack: LIFO (Last In First Out) data structure. Think of a stack of plates.
  • Operations: push(x) - add to top O(1), pop() - remove from top O(1), peek() - view top O(1)
  • Implementation: Array (dynamic array) or Linked List
  • Use Cases: Function call stack, undo/redo, parsing expressions, backtracking, matching pairs
// Stack implementation using array (Python)
stack = []
stack.append(x)    # push
top = stack.pop()  # pop
peek = stack[-1]   # peek (no removal)
is_empty = len(stack) == 0

// Java Stack
Stack stack = new Stack<>();
stack.push(x);
int top = stack.pop();
int peek = stack.peek();
💡 Pattern Recognition: If you see "matching pairs", "valid nesting", "nearest greater/smaller element", or "process in reverse order" - think Stack.

2. Monotonic Stack

What is Monotonic Stack?

A stack that maintains elements in monotonic (increasing or decreasing) order.

Monotonic Increasing Stack

// Maintains increasing order (bottom to top)
for each element:
    while stack not empty and top >= element:
        pop()  // remove elements breaking monotonic property
    push(element)
    
// Use case: Find next smaller element

Monotonic Decreasing Stack

// Maintains decreasing order (bottom to top)
for each element:
    while stack not empty and top <= element:
        pop()  // found answer for popped element
    push(element)
    
// Use case: Find next greater element
⚠️ Key Insight: Monotonic stack processes each element exactly once. Time complexity: O(n) despite nested loop. Each element pushed and popped at most once.

5. Queue Fundamentals

Core Concepts

  • Queue: FIFO (First In First Out) data structure. Think of a line of people.
  • Operations: enqueue(x) - add to back O(1), dequeue() - remove from front O(1), peek() - view front O(1)
  • Implementation: Circular array or Doubly Linked List
  • Use Cases: BFS, level-order traversal, scheduling, buffering
// Queue implementation (Python)
from collections import deque
queue = deque()
queue.append(x)        # enqueue (add to back)
front = queue.popleft() # dequeue (remove from front)
peek = queue[0]        # peek

// Java Queue
Queue queue = new LinkedList<>();
queue.offer(x);        // enqueue
int front = queue.poll(); // dequeue
int peek = queue.peek();

Deque (Double-Ended Queue)

Can add/remove from both ends in O(1). More powerful than stack or queue.

📝 Interview Tips:
  • Draw the stack state step-by-step for first few elements
  • Clarify: what to return if stack empty? Handle edge cases
  • Monotonic stack: decide increasing or decreasing based on problem
  • When to pop: "while" vs "if" - usually "while" to clear all invalid elements
  • Don't forget to process remaining elements in stack after main loop

Common Mistakes

  • ❌ Not checking if stack is empty before pop/peek
  • ❌ Confusing when to push index vs value (monotonic stack often needs indices)
  • ❌ Forgetting to handle remaining elements in stack after loop
  • ❌ Wrong monotonic order (increasing vs decreasing)
  • ❌ Not initializing result array properly (especially for "next greater" problems)
  • ❌ In circular array problems, forgetting to use modulo for indices
