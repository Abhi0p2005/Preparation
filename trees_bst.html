Trees & Binary Search Trees

Master tree traversals, BST properties, and recursive thinking

1. Tree Fundamentals

Core Concepts

  • Tree: Hierarchical data structure with root node and children. No cycles.
  • Binary Tree: Each node has at most 2 children (left, right).
  • Binary Search Tree (BST): left.val < node.val < right.val for all nodes.
  • Height: Longest path from root to leaf. Single node has height 0.
  • Depth: Distance from root. Root has depth 0.
  • Balanced Tree: Height difference of left and right subtrees ≤ 1 for all nodes.
// Tree Node Definition
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int x) { val = x; }
}

// Python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
💡 Recursive Thinking: Most tree problems solved recursively. Think: (1) Base case (null/leaf), (2) What to do at current node, (3) Combine results from left and right subtrees.

2. Tree Traversal

Traversal Types

Depth-First Search (DFS)

// Inorder: Left -> Root -> Right (gives sorted order in BST)
void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);
    visit(root);
    inorder(root.right);
}

// Preorder: Root -> Left -> Right (useful for copying tree)
void preorder(TreeNode root) {
    if (root == null) return;
    visit(root);
    preorder(root.left);
    preorder(root.right);
}

// Postorder: Left -> Right -> Root (useful for deletion)
void postorder(TreeNode root) {
    if (root == null) return;
    postorder(root.left);
    postorder(root.right);
    visit(root);
}

Breadth-First Search (BFS) / Level Order

// Using Queue
void levelOrder(TreeNode root) {
    if (root == null) return;
    Queue q = new LinkedList<>();
    q.offer(root);
    
    while (!q.isEmpty()) {
        int levelSize = q.size();
        for (int i = 0; i < levelSize; i++) {
            TreeNode node = q.poll();
            visit(node);
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
    }
}

3. Binary Search Tree (BST)

BST Properties

  • BST Property: For every node: all left descendants < node < all right descendants
  • Inorder Traversal: Gives sorted sequence
  • Search: O(log n) average, O(n) worst case (skewed tree)
  • Insert/Delete: O(log n) average, maintain BST property
  • Balanced BST: AVL, Red-Black trees guarantee O(log n) worst case
⚠️ Common Mistake: When validating BST, don't just check node.left < node < node.right. Must ensure ALL left subtree nodes < node < ALL right subtree nodes. Use min/max ranges.

108 Convert Sorted Array to BST Easy Pick middle element as root (balanced). Recursively build left subtree from left half, right subtree from right half. Divide and conquer.

6. Path Problems

Finding Paths

124 Binary Tree Maximum Path Sum Hard Track global max. For each node, max path through node = node.val + max(0, left_gain) + max(0, right_gain). Update global. Return node.val + max(0, max(left_gain, right_gain)).

129 Sum Root to Leaf Numbers Medium DFS with current number. At each node: num = num * 10 + node.val. If leaf, return num. Return sum of left and right subtrees.
257 Binary Tree Paths Easy DFS with path string. Add node to path. If leaf, add path to result. Recurse on children with updated path. Use "→" or "->" as separator.

7. Advanced Tree Problems

Complex Patterns

LC#ProblemDifficultySolution Approach
114 Flatten Binary Tree to Linked List Medium Morris-like approach: For each node, find rightmost node of left subtree. Connect it to right child. Move left subtree to right. Set left = null. Move to next right.
116 Populating Next Right Pointers Medium BFS level order. For each level, connect nodes left to right. node.next = next node in queue (or null at level end). O(1) space: use already-built next pointers.

337 House Robber III Medium Return pair: (rob_current, skip_current). rob = node.val + left.skip + right.skip. skip = max(left.rob, left.skip) + max(right.rob, right.skip). Return max at root.

8. Practice Strategy

Learning Path (3 Weeks)

  1. Week 1 - Basics & Traversal: Max Depth, Same Tree, Invert Tree, Inorder/Preorder/Postorder, Level Order
  2. Week 2 - BST & LCA: Validate BST, Kth Smallest, Insert/Delete in BST, LCA problems
  3. Week 3 - Construction & Paths: Construct from traversals, Serialize/Deserialize, Path Sum variants, Max Path Sum
📝 Interview Tips:
  • Always ask: is it a BST or just binary tree? Makes huge difference
  • Clarify: can tree be empty? Can values be negative?
  • Draw small examples (3-5 nodes) and trace your algorithm
  • State time/space complexity: most tree solutions O(n) time, O(h) space for recursion stack
  • Consider iterative solution if recursion stack depth is concern
  • For BST, always consider if inorder traversal helps
