2. TCP vs UDP

TCPUDP
Connection3-way handshakeconnectionless
Reliabilityreliable, retransmits, orderedunreliable, no ordering
Header20+ bytes8 bytes
Useweb, email, file transferstreaming, DNS, gaming, stock feeds
  • 3-way handshake: SYN → SYN-ACK → ACK.
  • 4-way teardown: FIN → ACK → FIN → ACK.
  • Ports: HTTP 80, HTTPS 443, SSH 22, DNS 53, FTP 21, DHCP 67/68.
  • Congestion control: Slow Start (double/RTT) → Congestion Avoidance (+1 MSS) → Fast Retransmit (3 dup ACK) → Fast Recovery (halve).

3. IP Addressing

  • IPv4: 32 bits, 4 octets. Private ranges (RFC 1918): 10.x.x.x, 172.16-31.x.x, 192.168.x.x — not routable publicly.
  • Subnet mask 255.255.255.0 = /24. CIDR notation 192.168.1.0/24.
  • Hosts = 2^(32−prefix) − 2. /24 → 254 usable.
  • Default gateway = router to reach other networks. DNS = domain → IP.
  • NAT = private→public translation. VLAN = logical LAN segmentation. Multicast = one sender, group of receivers.

4. Byte Order (networking classic)

  • Host byte order — your CPU's order (ARM/MIPS often little-endian). Network byte order — always big-endian.
  • Conversions: htons(), htonl(), ntohs(), ntohl().
  • Ethernet MAC (L2 frames) + PHY (physical signals). Switching = L2 by MAC; Routing = L3 by IP.

5. Sockets Programming (C)

// Server: socket → bind → listen → accept → recv → send → close
int sfd = socket(AF_INET, SOCK_STREAM, 0);
struct sockaddr_in addr = {.sin_family=AF_INET, .sin_port=htons(8080), .sin_addr.s_addr=INADDR_ANY};
bind(sfd, (void*)&addr, sizeof(addr));
listen(sfd, 5);
int cfd = accept(sfd, NULL, NULL);
read(cfd, buf, sizeof(buf)); write(cfd, "hello", 5);

// Client: socket → connect → send → recv → close
inet_pton(AF_INET, "127.0.0.1", &addr.sin_addr);
connect(sfd, (void*)&addr, sizeof(addr));

6. Embedded Networking Concepts

  • MIPS networking SoCs: high-throughput packet forwarding, often with hardware accelerators.
  • TCP/IP offload — NIC/hardware does protocol processing to free the CPU.
  • Ethernet MAC + PHY. NAT, VLAN, multicast as above.

8. Networking Flashcards

TCP vs UDP — pick one?

TCP: reliable/ordered (web, email, transfers). UDP: fast/loss-tolerant (streaming, DNS, VoIP, price feeds).

What is byte order and why care?

Little stores LSB first (ARM default); big stores MSB first (network). Misreading bytes corrupts protocol values.

What are htonl/ntohl for?

Convert host ↔ network (big-endian) byte order for sending/receiving protocol data.
