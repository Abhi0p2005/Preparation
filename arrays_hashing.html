Arrays & Hashing

Master fundamental array operations, hash-based lookups, and essential patterns

1. Array Fundamentals

Core Concepts

  • Array: Contiguous memory block storing elements of same type. O(1) access by index.
  • Dynamic Arrays: Resizable arrays (ArrayList/vector). Amortized O(1) append.
  • Common Operations: Access O(1), Search O(n), Insert/Delete O(n) (shift elements).
  • Key Techniques: Two pointers, sliding window, prefix sums, in-place modifications.
💡 Pro Tip: When modifying array in-place, consider working backwards to avoid overwriting needed elements. Use two-pointer technique for space optimization.

2. HashMap & HashSet Patterns

When to Use HashMap

  • Need O(1) lookup by key (vs O(n) array search)
  • Counting frequencies of elements
  • Storing seen elements to detect duplicates
  • Mapping values to indices or other data
  • Grouping elements by some property
⚠️ Important: HashMap average O(1) operations, but worst case O(n) with collisions. Space complexity O(n). Python dict, Java HashMap, C++ unordered_map.

3. Prefix Sum Technique

Concept

Prefix Sum: Precompute cumulative sums to answer range sum queries in O(1).

prefix[0] = 0
prefix[i] = prefix[i-1] + arr[i-1]  // sum of first i elements
sum(l, r) = prefix[r+1] - prefix[l]  // sum from index l to r
💡 Pattern Recognition: If problem asks about "subarray sum equals K", "count subarrays", or "range queries", consider prefix sum + hashmap.

4. Sliding Window Pattern

Two Types of Sliding Window

Fixed Size Window

// Pattern: maintain window of exactly k elements
sum = sum of first k elements
max_sum = sum
for i from k to n-1:
    sum = sum - arr[i-k] + arr[i]  // slide: remove left, add right
    max_sum = max(max_sum, sum)

Variable Size Window

// Pattern: expand right, shrink left when condition met
left = 0
for right from 0 to n-1:
    add arr[right] to window
    while (window invalid):
        remove arr[left] from window
        left++
    update result with current window
⚠️ Key Insight: Sliding window reduces O(n²) nested loops to O(n) by reusing computation. Works when subarray properties can be incrementally updated.

5. Two Pointers Technique

Common Patterns

Opposite Direction (Converging)

left = 0, right = n-1
while left < right:
    if condition_met:
        process and return
    elif need_increase:
        left++
    else:
        right--

Same Direction (Fast & Slow)

slow = 0
for fast from 0 to n-1:
    if arr[fast] meets condition:
        process arr[fast]
        slow++
💡 When to Use: Sorted arrays, finding pairs/triplets, partitioning, removing elements in-place, detecting cycles.

📝 Interview Tips:
  • Always clarify: array sorted? duplicates allowed? negative numbers?
  • State brute force first, then optimize
  • Discuss space-time tradeoffs
  • Test edge cases: empty array, single element, all same values
  • Prefer in-place modification when asked to minimize space

Common Pitfalls

  • ❌ Forgetting to handle empty array or single element
  • ❌ Not checking array bounds before accessing elements
  • ❌ Modifying array while iterating without proper index management
  • ❌ Using == for string comparison instead of .equals() (Java)
  • ❌ Not considering integer overflow in sum/product calculations
  • ❌ Forgetting to initialize hashmap with default values
