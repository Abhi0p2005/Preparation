0. The 5-Step Problem-Solving Approach (Group Coding / Interviews)

  1. Clarify (60 sec) — ask before writing: input size/range? negative/zero/duplicates? empty input? sorted? expected complexity?
  2. Think out loud (60 sec) — brute force first, then optimize. A wrong idea beats silent staring.
  3. Choose the data structure fast — match pattern → structure (table below).
  4. Code clean — readable names, one language, no clever one-liners you can't explain.
  5. Self-test (2 min) — 1 normal case + 1 edge case (empty, single, all same, max values).

3. Sliding Window

Fixed window (max sum subarray of size k)

int maxSumFixed(int[] nums, int k) {
    int sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i];
    int max = sum;
    for (int i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];   // slide: add right, remove left
        max = Math.max(max, sum);
    }
    return max;   // O(n) time, O(1) space
}

Variable window (smallest subarray with sum ≥ target)

int minSubarrayLen(int target, int[] nums) {
    int left = 0, sum = 0, minLen = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum >= target) {
            minLen = Math.min(minLen, right - left + 1);
            sum -= nums[left++];
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}

Timestamp-based (rate limiter — last 5 seconds)

Deque<Long> window = new ArrayDeque<>();
boolean allowRequest() {
    long now = System.currentTimeMillis();
    while (!window.isEmpty() && window.peekFirst() < now - 5000) window.pollFirst();
    if (window.size() >= 10) return false;
    window.offerLast(now); return true;

4. Two Pointers

// Two Sum (sorted)
int[] twoSum(int[] nums, int t){int l=0,r=nums.length-1;
  while(l<r){int s=nums[l]+nums[r];
    if(s==t)return new int[]{l,r}; else if(s<t)l++; else r--;} return new int[]{-1,-1};}

// Three Sum (unsorted) — sort, fix i, two-pointer the rest, skip duplicates
List<List<Integer>> threeSum(int[] nums,int t){
  Arrays.sort(nums); List<List<Integer>> res=new ArrayList<>();
  for(int i=0;i<nums.length-2;i++){
    if(i>0&&nums[i]==nums[i-1])continue;
    int l=i+1,r=nums.length-1;
    while(l<r){int s=nums[i]+nums[l]+nums[r];
      if(s==t){res.add(Arrays.asList(nums[i],nums[l],nums[r]));
        while(l<r&&nums[l]==nums[l+1])l++; while(l<r&&nums[r]==nums[r-1])r--; l++; r--;}
      else if(s<t)l++; else r--;}}
  return res;}

// Container With Most Water — move the shorter wall each step
int maxArea(int[] h){int l=0,r=h.length-1,max=0;
  while(l<r){max=Math.max(max,(r-l)*Math.min(h[l],h[r]));
    if(h[l]<h[r])l++; else r--;} return max;}

Worked example — Two Sum sorted [1,2,4,7,9] target 6: 1+9=10>6→r; 1+7=8>6→r; 1+4=5<6→l; 2+4=6 ✓. O(n), O(1).

6. Stack & Monotonic Stack

// Valid parentheses
boolean isValid(String s){Deque<Character> st=new ArrayDeque<>();
  for(char c:s.toCharArray()){if(c=='('||c=='{'||c=='[')st.push(c);
    else{if(st.isEmpty())return false;char o=st.pop();
      if((c==')'&&o!='(')||(c=='}'&&o!='{')||(c==']'&&o!='['))return false;}}
  return st.isEmpty();}

// Next Greater Element — monotonic decreasing stack of indices
int[] nge(int[] nums){int[] r=new int[nums.length];Arrays.fill(r,-1);
  Deque<Integer> st=new ArrayDeque<>();
  for(int i=0;i<nums.length;i++){while(!st.isEmpty()&&nums[st.peek()]<nums[i])r[st.pop()]=nums[i];
    st.push(i);} return r;}

// Sliding Window Maximum — monotonic deque (indices, values decreasing)
int[] maxSlidingWindow(int[] nums,int k){Deque<Integer> dq=new ArrayDeque<>();
  int[] r=new int[nums.length-k+1];int ri=0;
  for(int i=0;i<nums.length;i++){
    while(!dq.isEmpty()&&dq.peekFirst()<i-k+1)dq.pollFirst();
    while(!dq.isEmpty()&&nums[dq.peekLast()]<nums[i])dq.pollLast();
    dq.offerLast(i);
    if(i>=k-1)r[ri++]=nums[dq.peekFirst()];}
  return r;}

12. Topological Sort & Union-Find

Topological Sort (Kahn's algorithm)

int[] in=new int[n]; List<Integer>[] g=new ArrayList[n];
for(int i=0;i<n;i++)g[i]=new ArrayList<>();
for(int[] p:prereq){g[p[1]].add(p[0]); in[p[0]]++;}
Deque<Integer> q=new ArrayDeque<>();
for(int i=0;i<n;i++)if(in[i]==0)q.offer(i);
int[] res=new int[n];int idx=0;
while(!q.isEmpty()){int c=q.poll();res[idx++]=c;
  for(int nx:g[c])if(--in[nx]==0)q.offer(nx);}
return idx==n?res:new int[0];   // cycle detected if idx != n

Union-Find (DSU) — "are these two connected?"

class UF{int[] p,r;
  UF(int n){p=new int[n];r=new int[n];for(int i=0;i<n;i++)p[i]=i;}
  int find(int x){if(p[x]!=x)p[x]=find(p[x]);return p[x];}   // path compression
  void union(int a,int b){int pa=find(a),pb=find(b);if(pa==pb)return;
    if(r[pa]<r[pb])p[pa]=pb; else if(r[pa]>r[pb])p[pb]=pa; else{p[pb]=pa;r[pa]++;}}
  boolean connected(int a,int b){return find(a)==find(b);}}
// ≈ O(α(n)) ≈ O(1) amortized

13. Dynamic Programming

DP cheat-sheet

  • Use DP when: overlapping subproblems (same small calc repeated) + optimal substructure (answer built from subproblem answers).
  • Two styles: top-down (memoization) = recursion + cache; bottom-up (tabulation) = fill table small→big.
  • Recursion + memo is ACCEPTED in OAs — no need for fancy bottom-up.
  • Define the state (i, j, k, mask) → write recurrence on paper → code.

16. Rate Limiter Implementations

Token Bucket

class TokenBucket{long maxTokens,refillRate,tokens,last;
  TokenBucket(long max,long rate){maxTokens=max;refillRate=rate;tokens=max;last=System.nanoTime();}
  synchronized boolean allow(){refill(); if(tokens>0){tokens--;return true;} return false;}
  void refill(){long now=System.nanoTime();
    long added=(now-last)*refillRate/1_000_000_000;
    tokens=Math.min(maxTokens,tokens+added); last=now;}}

18. Recursion & Backtracking

  • Structure: base case (stop) + recursive case (call on smaller input).
  • Backtracking = recursion where you UNDO the last choice before the next (permutations, subsets, N-Queens, Sudoku). Exponential — small n only.
  • Example — subsets of [1,2]: choose/not-choose → { }, {1}, {2}, {1,2}.
