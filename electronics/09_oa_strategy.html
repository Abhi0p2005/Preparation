3. Pre-Submit Ritual (60 seconds)

  • Loop bounds: i < n vs i <= n, off-by-one
  • Types/overflow: use long/int64_t if sum can exceed 2.1e9
  • Defensive copies before mutating
  • Edge cases: empty, single, all same, all zeros, max values, negatives
  • Guard clauses at top: if (arr == NULL || n == 0) return ...;
  • Return type matches expected

4. MCQ Strategy

  • Read EVERY option before picking — distractors are the "trap" answers (unsigned conversion, sizeof, padding, octal literals).
  • For output questions: trace the code line by line with concrete values.
  • Two's complement: use range bounds (−128..127 for int8).
  • Watch: unsigned vs signed comparison, sizeof vs strlen, struct padding, pre/post increment, macro expansion, ++x vs x++.

5. ECE Quick-Fire Facts (memorize)

  • Unit: charge=Coulomb, resistance=Ohm, capacitance=Farad
  • Op-amp ideal: infinite gain/input impedance, zero output impedance
  • Nyquist rate = 2× max frequency
  • Cache faster than RAM; SRAM faster than DRAM
  • BJT current-controlled; MOSFET voltage-controlled
  • LED forward biased; Zener reverse breakdown
  • MCU has RAM/ROM/peripherals on-chip vs MPU
  • PWM for dimming/motor control
  • RISC: fixed-length, load-store (MIPS/ARM/RISC-V). CISC: x86
  • Von Neumann (single bus) vs Harvard (separate code/data)
  • Full adder: S=A⊕B⊕Cin, Cout=AB+Cin(A⊕B)
  • NAND/NOR universal gates

7. Coding Drill Bank (solve each < 5 min)

Easy

  • Reverse a string in place
  • Check palindrome
  • Largest & smallest in array
  • Count set bits (Brian Kernighan): while(n){n&=n-1;c++;}
  • Check power of 2: n && !(n&(n-1))
  • Set / clear / toggle a bit
  • Swap two ints without temp (XOR)

Medium

  • Remove duplicates from sorted array (in place)
  • Check anagrams
  • Find rightmost set bit
  • Implement strlen/strcpy/strcmp by hand
  • Circular buffer push/pop
  • Reverse array (two pointers)

Embedded-style

  • GPIO init + LED toggle at register level
  • UART putc (poll LSR then write DR)
  • Traffic-light state machine
  • ISR-safe counter (volatile flag + main loop)
  • sizeof(struct) puzzle — explain padding
  • Reverse bits of 32-bit int
  • Find middle of linked list (slow/fast)
  • Merge two sorted arrays / linked lists
